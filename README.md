# PYDEB

PYDEB is an open-source Python implementation of the DEB-Model, a surface energy-balance model for debris-covered glaciers. It is designed to be transparent, reproducible, and easy to adapt to different sites and meteorological forcing datasets, making the model accessible to the wider cryosphere community.

Status: version under review.
